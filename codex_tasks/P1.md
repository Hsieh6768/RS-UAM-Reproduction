# P1 — 领域对象、统一最短路与精确事件仿真

## 目标
构建公共对象（Request/Leg/Task/Vehicle/Flight/BatchSnapshot）、道路/航空网络统一路由、
M2状态仓库及`advance_to()`事件循环。本阶段以人工小图为主，不进行HALNS优化。

## 必读
D001–D004、D011、`docs/ARCHITECTURE.md`、`docs/TEST_AND_GATES.md` T-CORE。

## 具体实施
1. 配置校验与单位转换：m、m/s、s、目标min。14.9mph=6.660896m/s；
   170mph=75.9968m/s；统一有向最短路时间和提交后路径节点。
2. 设计稳定ID与只读快照；事件排序键（time, priority, seq, version），提前写明
   同一时刻边完成/下客/起飞/请求到达与调度的确定处理顺序及微型测试。
3. 车在有向边中途位置线性插值、当前边必须完成后才可更换路线，
   正确处理10:00:17到达及10:00:18接客在10:00:20批次前回放。
4. 航班固定出发/到达/预订座位，乘客跨车/航班/辅助步行等待链，
   不把候选优化耗时加到模拟时钟。
5. 建立请求、车辆、航班的状态转移及运行时不变量。
6. 重点核验 float道路边时间到整数秒事件的**唯一量化规则**，
   预言/实际时刻一致；如无法与已决定规则兼容，报告后停止该部分。
7. 仅人工图/少量数据对象测试；不启动真实数据10min以上模拟。

## Gate
CORE01–CORE16的相关测试、相同种子确定性、路线计划与事件时间一致、
未发生过早知道未来请求、不能丢失已执行前缀。记录新公共对象接口。
