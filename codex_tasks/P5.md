# P5 — M5 再平衡网格整数流、具体车移动与抢占

## 目标
实现论文式(25)–(31)三类运输流：1km网格，需求=唯一未满足有效请求数，
供给=真正空闲车数，网格中心大圆距离成本。使用Gurobi求解。

## 具体实施
- 供给小于/大于/等于需求分别设约束；x_ij非负整数，求解状态与最优性可解释。
- 将网格流映射成具体空闲车ID及目标网格最近可行道路节点；
  每车只有一个目标，x_ii不移动。
- 实际路径使用统一有向路网最短时间，而优化成本仍按网格中心球面距离。
- 正在再平衡的车辆在未来M3/M4可以被乘客任务抢占，但先完成当前路边；
  尚未完成再平衡的车不可每10秒被M5反复重设新目标。
- M5不直接接受请求；正常无新增再平衡不撤销已提交的乘客计划。
- noR完全不生成再平衡。
- 如果安装/许可证不可用报告环境阻塞，不擅自切换到另一优化器并宣称论文复现。

## Gate
M501–M509，微型整数运输穷举一致，车行驶时间与路由一致、跨批抢占测试通过。
