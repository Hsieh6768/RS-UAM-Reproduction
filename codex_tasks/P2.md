# P2 — M1 反向Pulse与真实Top-K

## 目标
对请求O/D与换乘点构建有向抽象行程网，执行反向Pulse并维护真正的最多K个合法方案，
请求初次提交时算一次、后续复用缓存。

## 具体实施
- 名义道路最短时间+名义空中飞行时间；实际航班排班与容量不在M1搜索中预测。
- K=5、正式运力行程<=3、换乘<=2，静态时间窗递推按D002，式(1c)疑点按已批准解释。
- 时间下界、换乘数、Top-K最差成本三种安全剪枝。
- 候选满K时删除最慢方案，绝不依赖未排序列表中的第一个较慢方案。
- 轻量结构签名检查重复，发现异常重复优先诊断网络构造。
- <500m整条请求P0已过滤，内部短地面接驳按D011辅助步行；如与编码相冲突必须给出小图案例。
- 15min额外差距剪枝**只保留未实现接口**，不得开启。
- 小图独立穷举允许的简单路径、比较时间/换乘/Top-K，独立于Pulse剪枝实现。
